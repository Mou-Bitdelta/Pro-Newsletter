# BitDelta COM crypto newsletter

Responsive HTML and CSS based on the supplied Figma frame. All imagery, graphics and fonts are included locally. No installation, JavaScript, or build step is needed.

## Open

Open `index.html` in your browser. Keep `styles.css` and `assets/` beside it.

## GitHub Pages

Upload the contents of this folder to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select the branch, and choose **/(root)**. Relative asset paths work in GitHub project sites.

This package uses its own crypto newsletter assets; it does not depend on the previous Pro newsletter repository. Images are optimized as WebP and SVG graphics are retained.

Dates, market figures, and article copy reproduce the supplied Figma design and are static. Edit content and links in `index.html`, and layout in `styles.css`.

Fonts: Archivo and Poppins, with included license files. The footer’s unavailable DIN font uses Archivo as a fallback.
